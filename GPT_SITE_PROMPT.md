# Промпт: сайт с автоподключением Karta-AD (для GPT / любого другого ИИ)

Скопируй блок ниже целиком, замени плейсхолдеры `{...}` и отдай любому ИИ (ChatGPT,
Claude и т.д.) — на выходе получишь готовый статический сайт, который при обычной
загрузке страницы сам подключает каталог, корзину, оформление заказа и карту.

## Подготовка (один раз)

1. **UUID бизнеса** — «Мой бизнес» → вкладка «AI-сайт» → строка сниппета:
   в `<script ... data-business="....">` уже вшит твой UUID.
2. **Координаты** (`lat`, `lng`) — карточка бизнеса / карта в приложении.
3. **Виджет на проде** — файл `widget.js` собирается вместе с приложением:
   коммиты должны быть запушены, Vercel пересоберёт, и
   `https://karta-ad.vercel.app/widget.js` откроется (проверь в браузере до запуска сайта).

```text
Ты — опытный веб-разработчик. Создай полноценный сайт-лендинг для бизнеса
«{BUSINESS_NAME}» (город: {CITY}, адрес: {ADDRESS}, телефон: {PHONE}).

# Главное требование: всё подключается автоматически при загрузке страницы

Сайт интегрирован с платформой Karta-AD. Свой бэкенд, свою корзину, свои формы
заказа и свои ключи API НЕ пиши — всё это уже даёт официальный виджет Karta-AD.
Интеграция — это ровно одна строка, вставь её перед </body>:

<script src="https://karta-ad.vercel.app/widget.js" data-business="{BUSINESS_UUID}" data-lang="ru" defer></script>

Что эта строка делает сама, без твоего кода (не повторяй логику виджета):
- сразу при загрузке страницы виджет запрашивает данные бизнеса по UUID
  (название, товары, цены, координаты) и показывает их;
- если на странице нет якорей — в правом нижнем углу автоматически появляется
  плавающая кнопка «🛒 Заказать»: каталог, корзина, оформление заказа;
- карта выбора адреса доставки встроена в оформление и включена по умолчанию
  (Leaflet + OpenStreetMap, пин можно двигать, адрес подставляется автоматически);
- оформленный заказ сразу попадает в админку Karta-AD («Мой бизнес» → «Заказы»),
  оплата — наличными при доставке;
- повторная загрузка скрипта не создаёт второй виджет;
- на мобильных виджет не перекрывает контент.

Якоря для встроенных секций (вставь в разметку туда, где секция должна стоять;
без них работает плавающая кнопка — выбери один режим):

<div data-karta="catalog"></div>   <!-- каталог товаров -->
<div data-karta="cart"></div>      <!-- корзина -->
<div data-karta="checkout"></div>  <!-- оформление заказа (без него форма живёт в секции корзины) -->

# Обязательная карта «Как нас найти» — с автозагрузкой, без кликов

Отдельная секция карты бизнеса, которая инициализируется сама при загрузке страницы:
- Leaflet 1.9.4 с unpkg (CSS + JS), тайлы OpenStreetMap;
- центр карты [{LAT}, {LNG}], zoom 16, маркер с подписью «{BUSINESS_NAME}»;
- карта рисуется сразу на DOMContentLoaded (пользователь не должен кликать,
  чтобы она появилась);
- под картой: адрес, телефон (ссылка tel:), кнопка «Проложить маршрут»
  (абсолютная ссылка на openstreetmap.org или Google Maps, target="_blank");
- если Leaflet не загрузился (нет интернета) — вместо карты ссылка
  «Открыть на OpenStreetMap», страница при этом не ломается.

# Структура сайта

1. Шапка: логотип/название, навигация по секциям, телефон, кнопка «Заказать».
2. Hero: заголовок, короткое УТП, кнопки «Смотреть каталог» (ведёт к секции
   каталога/к плавающей кнопке виджета) и «Как нас найти» (скролл к карте).
3. О нас / преимущества: 3–4 карточки.
4. Каталог — якорь data-karta="catalog" (или плавающая кнопка, если якоря нет).
5. Доставка: зона, сроки, «Бесплатно от {FREE_FROM} TJS», оплата наличными.
6. Карта «Как нас найти» (см. выше).
7. Контакты: телефон, WhatsApp (если есть), адрес, часы работы.
8. Футер: название, копирайт, ссылка на приложение Karta-AD.

# Технические требования

- Чистая статика: index.html (+ styles.css и app.js по желанию), без сборщиков,
  фреймворков и Node — работает на любом хостинге после загрузки файлов.
- Мобильный первый, адаптив 320–1920px, тёмная тема по prefers-color-scheme.
- Ванильный JS. Запрещено: свои корзины, свои формы заказа, fetch к API
  Karta-AD своими руками, любые ключи/токены кроме data-business UUID.
- Безопасность: данные, приходящие извне (товары, название), вставляй через
  textContent/создание элементов, не через innerHTML.
- i18n: русский язык.
- SEO: title, meta description, og-теги, одна H1, семантические теги.

# Формат ответа

Полный рабочий код всех файлов целиком — без сокращений, без «...»,
без «остальной код без изменений». Плейсхолдеры оставь ТОЛЬКО для:
{BUSINESS_UUID}, {LAT}, {LNG}, {PHONE}, {ADDRESS}. После кода — короткая
инструкция: куда вставить UUID и координаты, как проверить, что заказ дошёл
в админку (оформить тестовый заказ и открыть «Мой бизнес» → «Заказы»).

# Самопроверка перед ответом

- строка виджета присутствует ровно один раз и стоит перед </body>;
- карта инициализируется сама при загрузке, без единого клика;
- якоря data-karta стоят в своих секциях (или явно указано, что работает
  плавающая кнопка);
- страница открывается без ошибок в консоли;
- ни одного своего ключа API и ни одного своего обработчика заказа.
```
